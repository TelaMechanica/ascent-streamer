# Platform inspection summary

The original development platform was a Raspberry Pi Zero 2 W running 32-bit Raspberry Pi OS Bookworm with the pre-April-2025 iUniker MZP351HV00BR GPIO panel. Hardware H.264 decoding and NetworkManager AP support were observed. The built-in radio supports 2.4 GHz.

Personal network names, device addresses, saved profile identifiers and private backup records are omitted. Vendor installers were inspected but not executed. The installer contains the bounded KMS configuration for this older panel; other panel revisions require separate verification.
