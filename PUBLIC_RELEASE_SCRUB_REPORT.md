# Ascent Streamer public export review

This is a fresh source export with no internal Git history. Historical originals are preserved privately.

Removed development network addresses, saved Wi-Fi profile identifier, observed receiver radio address and pinned SSH host fingerprint. Device-specific network fixtures use generic example names. The station-presence fixture contains no address literal. Deployment requires the operator to supply an address and verified host fingerprint. PNG metadata was removed from splash assets and embedded branding without changing pixels.

Excluded captures, logs, saved settings, backups, original archives and internal project history. No personal Wi-Fi credential or computer name was found in the exported application source. Generic product defaults, interface names, service paths and local receiver/hotspot endpoint defaults remain because the application uses them. No private credential was found requiring rotation. This export does not certify prior private copies as safe to publish.

Playback/network behavior is retained. The package is named Ascent Streamer; compatible installation paths remain unchanged. Historical hardware observations are anonymized and retain their limitations; this publication performs no hardware test.

Validation: all 53 standalone host tests passed with loopback server access. Python, installer shell, embedded installer Python and page JavaScript syntax checks passed. Privacy scans cover text files, device-address patterns, local user paths, token/key patterns and PNG metadata. Splash images were visually inspected. No new hardware qualification is claimed.
