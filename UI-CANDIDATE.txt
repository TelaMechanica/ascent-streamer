Install using INSTALL.md in the package. Installation changes the Pi and must be
performed deliberately. A page-only update is sufficient on an existing rc2 Pi:
back up /opt/ascent-viewer/web/index.html and replace it with web/index.html.
For page-only deployment VERSION stays rc2; ui1 identity applies to a full update.
Do not run historical recovery scripts or change automatic operation for this UI.

to the input release. Original transfer archive and withdrawn releases preserved.
